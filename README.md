# 🎨 Tugas 2 — Belajar Tampilan HTML dengan CSS

## 📚 Tentang Tugas

Repository ini merupakan tugas pembelajaran **HTML dan CSS**.

Pada tugas ini saya belajar bagaimana membuat sebuah halaman HTML kemudian memberikan **warna, ukuran, posisi, jarak, dan desain** menggunakan CSS.
